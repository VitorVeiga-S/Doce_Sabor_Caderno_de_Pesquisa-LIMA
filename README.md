
# Atividade de Pesquisa - Linguagem de Marcação

## Descrição da Atividade

Atividade de pesquisa da unidade curricular Linguagem de Marcação, do curso Técnico em Desenvolvimento de Sistemas do SENAI.

O trabalho consiste em estudar e aplicar conceitos de HTML5 e CSS no desenvolvimento de um site para a confeitaria fictícia Doce Sabor.

## Conteúdos abordados

- Estrutura básica de um documento HTML5.
- Tags semânticas e acessibilidade.
- Elementos interativos com HTML.
- Criação de formulários para encomendas.
- Variáveis CSS, Grid, responsividade e efeitos visuais.

## Objetivo

Compreender a utilização das linguagens HTML e CSS na construção de páginas web, aplicando boas práticas de estruturação, semântica, acessibilidade e estilização.

## Entrega

A atividade foi desenvolvida por meio de pesquisa e resolução das 12 questões propostas, com exemplos de código e explicações sobre os conceitos estudados.

## Tecnologias e fontes

- CSS3
